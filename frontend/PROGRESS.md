## Phase 2 notes

- Live check (headless Chrome, real API): too-low bid shows the server's minimum; using the minimum bid places it; a rival's higher bid appears on the page within 3 seconds; my bids shows "Outbid"; buy now completes and the sale closes with "You won this one".
- Minimum increment is server config ($1 today). The app suggests current price plus $1. The server's minimum always wins.
- The bid's stored status is never updated by the backend, so my bids works out Leading, Outbid, Won or Lost from the sale.
- Live refresh is polling every 3 seconds, not sockets.
- **Fixed in phase 3 (option A, one transaction):** buy-now, offer accept and auction close now resolve the sale, move the stock, and create the order in one transaction. A failed order rolls the whole thing back, so no resolved sale is left without an order. Live-checked: a failing order leaves the sale OPEN, no order and stock unchanged (7 checks pass).
